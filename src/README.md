# Mergington High School Activities

A website for browsing extracurricular activities at Mergington High School and helping teachers manage student registrations.

## Features

- Browse activity descriptions, schedules, current participants, and available spots
- Search activities and filter by category, day, or time
- Log in as a teacher to register students for activities or unregister them
